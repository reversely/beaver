Rover

Beaver runs on a Raspberry Pi 5 rover with a camera, a microphone, and a speaker. A visitor asks a question aloud, and the rover answers aloud in each language the site has chosen. The same guide runs in a web browser for classrooms without a rover.

  • Questions by voice or keyboard
  • A camera frame sent with each question
  • Replies in English, French, or both
  • The visitor's own language added to each sentence
  • A notebook of vocabulary and concepts from each exchange
  • A wake word or a button to start listening

Knowledge

Beaver answers with Gemini under a guide prompt that sets its topics and rules.

Guide prompt rules

  • At most 3 short sentences, written to be heard
  • Say so when unsure of a fact
  • Never invent dates, names, or figures
  • Answer a question outside these topics briefly, then suggest a Canadian one
